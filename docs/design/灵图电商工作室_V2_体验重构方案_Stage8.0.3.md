# 灵图电商工作室 V2 体验重构方案

> 版本定位：Stage 8.0.3 体验升级  
> 核心目标：把“技术配置工具”重构成“电商图片生产工作台”。

---

## 一、产品定位

灵图电商工作室不是普通 AI 生图页面，也不是模型测试工具。

它应该让电商卖家完成一条完整任务：

```text
上传商品图
→ 选择平台和制作类型
→ 自动识别商品
→ 自动生成图片策划
→ 逐张生成候选
→ 选择首选图
→ 打包导出
```

用户不需要理解：

- 模型协议
- 能力标签
- 参考图传输方式
- Provider adapter
- fingerprint
- run ID

这些技术信息只放在“高级设置”中。

---

## 二、设计原则

### 1. 第一屏先做图，不先配模型

首页第一屏只强调：

- 拖入商品图片
- 选择平台
- 选择制作类型
- 开始创建

API 设置放在右上角设置页，不占主流程。

### 2. 用电商卖家的语言

使用：

- 商品主图
- 五图 Listing
- 详情页
- 卖点
- 场景
- 参考图
- 首选图
- 打包下载

避免直接展示：

- protocol
- capability
- image_generation
- asyncImage
- providerProfileId

### 3. 自动优先，手动兜底

系统应该自动完成：

- 图片格式校验
- 主参考图选择
- 模型能力判断
- 三角色推荐
- 平台比例和规范
- 五图任务拆分
- Prompt 生成

用户仍可在高级设置中手动修改。

### 4. 结果管理重于单次生成

每个项目都应该围绕：

```text
图1 主图
图2 结构
图3 功能
图4 场景
图5 细节
```

每张图有：

- 当前策划
- 候选图
- 首选图
- 重新生成
- 删除非首选
- 下载

# 四、首页设计

## 4.1 首页结构

首页采用“主操作区 + 最近项目”布局。

### 主操作区

标题：

```text
开始制作商品图片
```

副标题：

```text
拖入商品图，选择平台和制作类型，系统会自动完成后续策划。
```

核心拖拽区：

```text
拖入商品图片
支持 JPG、PNG、WebP，最多 14 张
也可以点击选择或 Ctrl+V 粘贴
```

上传后立即显示：

- 本地缩略图
- 文件名
- 删除
- 清空
- 拖动排序
- 主图标记

### 基础信息

只保留：

- 商品名称
- 平台
- 制作类型
- 默认比例

制作类型：

```text
商品主图
五图 Listing
详情页长图
批量 SKU
```

### 主按钮

```text
创建项目并上传
```

创建后：

1. 自动创建项目
2. 批量上传图片
3. 第一张设为主参考图
4. 前 8 张默认参与识别
5. 前 4 张默认参与生成
6. 自动进入项目工作台

---

# 五、项目工作台设计

采用三栏布局。

## 5.1 左栏：商品与参考图

内容：

- 项目名称
- 商品名称
- 平台
- 核心卖点
- 目标人群
- 使用场景
- 参考图

参考图区域必须支持：

- 点击上传
- 拖拽上传
- Ctrl+V 粘贴
- 上传进度
- 继续添加
- 排序
- 设为主图
- 参与识别
- 参与生成
- 图片角色

拖入时显示整块高亮遮罩：

```text
松开即可添加商品参考图
```

## 5.2 中栏：制作流程

顶部流程：

```text
1 商品资料
2 商品识别
3 图片策划
4 生成与导出
```

每一步显示：

- 当前状态
- 缺少内容
- 下一步按钮

主要区域根据制作类型变化。

### 五图 Listing

显示五个标签：

```text
图1 主图
图2 结构
图3 功能
图4 场景
图5 细节
```

每张图显示：

- 制作目标
- 主卖点
- 画面结构
- 文案建议
- 生成提示词
- 比例
- 生成按钮

普通用户默认不直接看完整 Prompt，可通过“查看高级提示词”展开。

## 5.3 右栏：候选与首选

当前图的结果区：

- 当前首选图
- 候选图列表
- 重新生成
- 设置首选
- 下载
- 删除非首选
- 加载更多

顶部显示整套进度：

```text
已完成 3 / 5
还缺图2、图4首选图
```

五张都完成后显示：

```text
下载整套首选图
```

# 六、模型与 API 设置重构

## 6.1 普通模式

普通模式只显示：

- 配置名称
- 服务商
- Base URL
- API Key
- 获取模型
- 模型选择
- 自动识别结果
- 保存配置

模型选择流程：

```text
选择服务商
→ 填写 API Key
→ 获取模型
→ 选择模型
→ 自动识别能力
→ 保存
```

保留：

```text
手动填写模型 ID
```

用于不支持模型列表的第三方接口。

## 6.2 自动能力识别

系统根据：

- 服务商
- Base URL
- 模型 ID
- 模型名称
- Provider adapter

自动输出：

- 文本
- 推理
- 视觉
- 图片生成
- 是否支持参考图
- 推荐角色
- 自动协议
- 判断原因

示例：

```text
DeepSeek Reasoner
支持：文本、推理
推荐：策划与提示词
不支持：商品识图、图片生成
```

```text
Gemini Image
支持：视觉、图片生成、参考图
推荐：图片生成
```

协议和能力标签放入“高级设置”，默认收起。

## 6.3 三角色自动匹配

三个角色：

```text
商品识图
策划与提示词
图片生成
```

增加按钮：

```text
一键自动匹配
```

规则：

- 只填充未绑定角色
- 不覆盖已锁定角色
- 推荐结果先预览
- 用户确认后保存
- 图片生成只允许已验证支持参考图的模型
- DeepSeek 不得进入图片生成
- 未知兼容模型默认只有文本能力

每个角色卡片显示：

- 当前配置
- 服务商
- 模型
- 能力
- 推荐原因
- 更换
- 锁定
- 清除

# 八、本地存储设置

设置内容：

```text
当前素材路径
检测路径
保存路径
打开文件夹
迁移已有素材
恢复默认路径
```

默认路径可以继续使用项目目录下的 storage。

推荐用户路径：

```text
D:\灵图素材库
```

路径迁移要求：

- 先统计文件数量和容量
- 用户确认后执行
- 复制完成后校验
- 更新数据库路径
- 旧目录暂不删除
- 失败时保持旧路径继续可用

# 十一、视觉风格

参考 DesignKit 的信息层级，但不照搬品牌。

推荐：

- 深色背景
- 紫色作为主操作色
- 绿色表示完成
- 黄色表示待配置
- 红色只表示失败
- 卡片边界清晰
- 少用大面积纯黑空白
- 页面标题 22–28px
- 正文 14–16px
- 状态标签不低于 12px
- 主要按钮高度不低于 42px

避免：

- 大量技术字段直接平铺
- 10px 小字
- 过度粗黑字体
- 所有区域同一层级
- 空页面没有下一步引导

---

# 十二、自动化体验

应该自动完成：

1. 拖图后识别有效图片
2. 自动排序和主图预选
3. 自动创建项目并上传
4. 自动识别模型能力
5. 自动推荐三角色
6. 自动匹配平台规范
7. 自动生成五图策划
8. 自动轮询生成状态
9. 自动刷新候选历史
10. 自动提示还缺哪些首选图

不得自动完成：

- 未确认就覆盖已有策划
- 未确认就替换角色绑定
- 未确认就连续调用五次收费生图
- 未确认就删除候选或项目

# 十四、验收标准

1. 用户进入首页后 10 秒内知道怎么开始。
2. 用户无需先进入 API 设置也能创建项目和上传图片。
3. 首页和工作台都能拖拽图片。
4. 支持 Ctrl+V 粘贴图片。
5. 模型协议和能力默认自动判断。
6. DeepSeek 不会被误配为图片生成。
7. 图片模型能自动推荐给图片生成角色。
8. 三角色可以分别绑定不同服务商。
9. 普通页面不出现难懂技术字段。
10. 五图进度和缺失首选图清晰可见。
11. 本地素材库免登录。
12. 不新增收费调用。
13. 所有旧 CI 继续通过。

# 十六、最终产品感受

```text
我正在制作一套电商图片
```

而不是：

```text
我正在配置一个复杂的 AI API 工具
```

产品最终关键词：

```text
先拖图
自动识别
自动策划
逐张生成
选择首选
整套导出
```
